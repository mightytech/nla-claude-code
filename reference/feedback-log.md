# Feedback Log

Accepted items from external feedback — things others noticed that the maintainer agreed with after triage. The sibling of the friction log.

## How Feedback Differs from Friction

- **Friction log** = things you noticed about this NLA
- **Feedback log** = things others noticed that you agreed with

Both feed into `/maintain` sessions.

## How to Use This Log

Items arrive here after triage — via `/check-feedback` or any external feedback mechanism. During `/maintain`, process pending items into documentation or convention changes. Resolved items move to `feedback-log-archive.md`.

### Entry Format

#### YYYY-MM-DD: [Brief title]

- **Source:** Where this feedback came from
- **Verdict:** Why it was accepted
- **Status:** pending | in-progress | resolved (YYYY-MM-DD: description)
- **What to do:** The action to take
- **Why it was accepted:** What makes this feedback valid

Not all fields are required.
